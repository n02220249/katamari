# Katamari — Symbolic Transformation Project

## Project purpose

This repository tracks a research/design project exploring the symbolic and cultural paths that can converge on the central transformation pattern represented by Katamari:

**rolling → gathering / incorporation → consumption / processing → destruction / recombination → growth → transformation → renewal / new world**

The project distinguishes between:
- **Documented influence** — evidence that a creator, work, tradition, or source directly influenced Katamari.
- **Symbolic participation** — a tradition independently expressing a similar structural pattern.
- **Structural convergence** — different traditions arriving at similar transformation logic without requiring direct historical influence.

## Current checkpoint — v0.1

### Egyptian / scarab path

A major symbolic path under investigation is ancient Egyptian solar renewal, especially the scarab/Khepri motif.

Core structural correspondence:

**scarab / rolling sun → movement across the sky → renewal / rebirth → transformation**

For the Katamari comparison:

**rolling sphere → gathering/incorporation → increasing mass → transformation → new world**

This is currently a **symbolic research hypothesis/path**, not a claim of documented direct influence.

## Research paths

### 1. Egyptian scarab / Khepri
Investigate:
- Khepri and the scarab as a symbol of becoming/renewal
- Solar-cycle imagery and rebirth

### 2. Other possible convergent traditions
Future research may test additional traditions against the same transformation grammar without assuming direct influence.

## Design language

The visual/design exploration can combine:
- Katamari's spherical rolling/gathering form
- Egyptian scarab geometry and imagery
- Solar-renewal symbolism
- Layered transformation from small object to world-scale entity
